# Правило ведения истории изменений (CHANGELOG.md)

При выполнении любых доработок, исправлений багов или оптимизаций проекта **ВСЕГДА** фиксируй изменения в файле `CHANGELOG.md` в корне проекта на русском языке.

### Формат записи в `CHANGELOG.md`:

```markdown
день месяц год
- изм
- изм
- изменения
- изм

-------------------------
```

Пример:
```markdown
22 августа 2026
- Оптимизирована частота сетевых запросов и устранен спам на серверы
- Удален агрессивный 8-секундный интервал опроса в MainLayout
- Удалена виртуализация списка чатов, добавлена порционная подгрузка

-------------------------
```

Каждый новый блок обновлений добавляется сверху или снизу существующих и обязательно отделяется разделителем `-------------------------`.
