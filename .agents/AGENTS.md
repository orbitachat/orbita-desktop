# Правила разработки и работы агента для Orbita

## 1. Обязательный бэкап
- При каждом внесении изменений в код или при запросе бэкапа (`бэкап`, `сохрани`, `зафиксируй`):
  Запустить терминальную команду: `node scripts/backup.js "<краткое описание изменений на русском>"`
- Скрипт автоматически создаст Git-коммит и сохранит архив в `E:\Orbita_Backups\`.
- Сообщить пользователю результат создания бэкапа.

## 2. Запрет нативных подсказок (`title="..."`)
- **СТРОГО ЗАПРЕЩЕНО** использовать атрибут `title="..."` на кнопках и элементах.
- Для доступности использовать только `aria-label="..."`.

## 3. Двуязычная локализация (RU / EN)
- Любой новый или изменённый UI текст обязательно синхронно добавлять в оба файла:
  - `src/locales/ru.json`
  - `src/locales/en.json`
- В коде интерфейса использовать строго `t(...)`.

## 4. Полный запрет на комментарии в коде
- **СТРОГО ЗАПРЕЩЕНО** писать любые комментарии в коде (`//`, `/* ... */`, JSDoc, TODO).
- Весь изменяемый код должен быть чистым и самодокументируемым.

## 5. Экономия токенов и стандарт качества
- **Лаконичность**: Отвечать максимально кратко, чётко и по делу без длинной вступительной воды.
- **Точечные правки**: Вносить изменения строго локально через подстрочные замены (`replace_file_content`), не перезаписывая большие файлы целиком.
- **Обязательный билд**: Всегда проверять код через `npm run build` перед отчётом пользователю.
