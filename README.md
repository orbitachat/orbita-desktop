> High-performance, end-to-end encrypted desktop messenger with native Windows integration, real-time messaging, and low-latency voice and video calls.

---

## 🌟 Ключевые возможности (Core Capabilities)

- **Сквозное шифрование (End-to-End Encryption)**: Реализация протокола Double Ratchet (X25519, HKDF, AES-GCM / ChaCha20-Poly1305) гарантирует полную приватность и защиту данных (Zero-knowledge forward secrecy and backward privacy).
- **Чистый современный темный интерфейс (Modern Dark UI)**: Движок интерфейса основан на Material Design 3 с адаптивными палитрами и минималистичным дизайном, сфокусированным на удобстве.
- **Локальная транскрипция голосовых сообщений**: Поддержка обработки голосовых сообщений прямо на вашем устройстве для максимальной конфиденциальности.
- **Очистка метаданных файлов**: Автоматическое удаление метаданных файлов при отправке, защищающее вашу анонимность.
- **Низкая задержка (Low-Latency Calls)**: High-definition peer-to-peer и групповые аудио/видео звонки на базе LiveKit и WebRTC.

---

## 🛠 Стек технологий (Technology Stack)

- **Electron** — Application Shell (Chromium, Node.js)
- **React & TypeScript** — Frontend Architecture (React 19, Vite, TailwindCSS)
- **Rust** — Native Extension (`napi-rs`, Win32 API, Hardware-accelerated Cryptography)
- **Supabase** — Gateway & Relay (Cloudflare Workers, Vercel Serverless)

## 🚀 Быстрый старт (Getting Started)

### Предварительные требования (Prerequisites)
- [Node.js](https://nodejs.org/) (v20 или новее)
- [Rust и Cargo](https://rustup.rs/) (для компиляции модулей `native/`)

### Клонирование и установка (Installation)
```bash
git clone https://github.com/orbitachat/orbita-desktop.git
cd orbita-desktop
npm install
```

### Разработка (Development)
```bash
npm run dev
```

### Сборка проекта (Production Build)

**Windows Installer:**
```bash
npm run electron:build
```
Compiled setup executable will be generated in `release/setup_1.0.18.exe`.

*(Note: Ensure you have the necessary build tools installed for your target OS. Linux and macOS builds can be generated by adjusting the electron-builder target in `package.json`).*

## 🏗 Архитектура проекта (Project Structure)

Краткое описание основных директорий проекта:

```text
orbita-desktop/
├── api/                  # Serverless token gateway and relay endpoints
├── electron/             # Electron main processes (main, preload, app lifecycle)
├── native/               # Native Rust addon (N-API, Win32 system tray, crypto)
├── public/               # Static assets, fonts, sounds, icons
├── src/                  # (Renderer) React frontend, UI components, states
│   ├── components/       # Interface components (chats, calls, settings)
│   ├── lib/              # Cryptographic algorithms and protocols
│   ├── store/            # State management (Zustand)
│   ├── App.tsx           # Primary application window
│   └── call-main.tsx     # Dedicated call window entry point
└── supabase/             # Supabase edge functions and schemas
```
