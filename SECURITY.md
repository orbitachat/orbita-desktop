# Security Policy

## Supported Versions

Currently, only the latest release of Orbita Desktop is supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of Orbita very seriously, especially given its focus on End-to-End Encryption (E2EE) and user privacy.

If you discover a security vulnerability, we ask that you report it to us privately to give us time to patch it before it is disclosed publicly.

**Please DO NOT report security vulnerabilities via public GitHub issues.**

Instead, please email the details of the vulnerability to the project maintainers or use the GitHub Security Advisory private reporting feature if enabled.

### What to include in your report:
- A description of the vulnerability.
- Steps to reproduce the issue.
- Potential impact (e.g., bypass E2EE, remote code execution, XSS).
- Any proof of concept (PoC) code or screenshots.

We will acknowledge receipt of your report within 48 hours and provide an estimated timeline for resolution.
