# Release 2.0.0

В этом обновлении мы провели масштабный рефакторинг системы безопасности и исправили ряд критических проблем.

Ключевые изменения:
- Гибридное шифрование локальных данных: Внедрена защита локального ключа с помощью системного хранилища (Electron safeStorage) и опционального PIN-кода.
- Исправление критического сброса сессий: Устранена проблема, из-за которой при отсутствии поддержки safeStorage в ОС или при первой миграции мог генерироваться новый ключ, что приводило к потере всех чатов после перезапуска.
- Мгновенная доставка сообщений: Значительно ускорена доставка и обработка входящих сообщений. Убраны блокирующие вызовы к Supabase при получении сообщений и отчетов о прочтении.
- Синхронизация профиля: Теперь короткое имя (username) и информация о себе (bio) надежно сохраняются локально, синхронизируются с базой данных и включаются в резервные копии аккаунта.
- Улучшенная отказоустойчивость шифрования: Добавлен надежный фолбэк на Web Crypto API в случае недоступности Rust-модуля для алгоритма Double Ratchet.
- Переход на использование IPC: Ключевые данные профиля и чатов больше не хранятся в открытом виде в localStorage. Вместо этого они шифруются и безопасно сохраняются на уровне файловой системы через IPC.

Для установки скачайте прикрепленный exe-файл и запустите его на вашем ПК.
