# Orbita Desktop 2.0.0

Мажорное обновление платформы Orbita Desktop, включающее глубокий рефакторинг безопасности, оптимизацию хранилища данных и исправление критических уязвимостей синхронизации.

## Безопасность и хранилище данных
- Аппаратное шифрование базы данных: все локальные сообщения, чаты и состояние авторизации шифруются алгоритмом AES-256-GCM на уровне встроенного хранилища SQLite.
- Полная изоляция от системных ключей Windows: устранены сбои дешифрования и потери ключей при перезапусках системы и смене профиля пользователя.
- Криптографическая защита по коду доступа: при установке пароля в приложении мастер-ключ контейнера шифруется через PBKDF2-HMAC-SHA256 (100 000 итераций) с удалением открытых ключей с диска. Данные расшифровываются исключительно в оперативной памяти после ввода пароля.
- Защита от потери сессии при инициализации: устранена проблема гонки состояний (race condition), из-за которой ранние системные события могли перезаписывать сохранённую базу данных пустым состоянием до завершения гидратации.

## Производительность и передача сообщений
- Мгновенная доставка сообщений: оптимизирована обработка входящих сообщений и отчётов о доставке/прочтении без блокирующих синхронных вызовов к фоновым сервисам.
- Отказоустойчивое сквозное шифрование (E2EE): реализован прозрачный фолбэк протокола Double Ratchet на стандартный Web Crypto API при недоступности бинарных нативных модулей.
- Безопасное хранение через IPC: чувствительные данные полностью перенесены из открытого веб-хранилища localStorage в изолированный защищённый IPC-слой Electron.

## Профиль и синхронизация
- Синхронизация расширенных данных профиля: имя пользователя (username) и описание профиля (bio) надёжно сохраняются локально, синхронизируются с облаком и корректно восстанавливаются из резервных копий.
- Полная согласованность метаданных аккаунтов при переключении и восстановлении профилей.

## Инструкция по обновлению
Для обновления скачайте прикрепленный файл установщика Orbita Desktop setup_2.0.0.exe и запустите его. Все ваши существующие чаты и ключи будут сохранены автоматически.
